# 오늘의 묵상 — 매일 바뀌는 말씀 CLI 지시서

**사용법:** 이 폴더(`verses/`)를 프로젝트 루트에 풀고 CLI에 이렇게 말하세요.

> verses/DAILY-VERSES.md 읽고 그대로 해줘.

---

## 이 작업이 하는 일

1. `daily-verses.refs.json`에 있는 183개 구절의 `text`를 **개역한글판 원문 그대로** 채웁니다.
2. 앱의 데이터 파일로 만듭니다.
3. 오늘의 묵상 카드에 날짜별로 한 절씩 보여줍니다.

구절 선택과 순서는 이미 정해져 있습니다. **구절을 추가·삭제하거나 순서를 바꾸지 않습니다.**

### git

단계마다 로컬 커밋만 합니다. `push`, `merge`, `rebase`, PR 생성은 하지 않습니다.

## 1. 본문 채우기 — 반드시 코드로, 원문 그대로

### 왜 개역한글인가

- **개역한글판**: 대한성서공회가 무료 사용을 허용합니다. 조건은 두 가지입니다.
  출처를 표시할 것, 본문을 바꾸지 말 것.
- **개역개정판**: 웹·앱에 쓰려면 번역본마다 1년에 100만 원의 사용 허락이 필요합니다.
  그래서 이번 작업에는 쓰지 않습니다.

### 규칙

- 본문은 **기억으로 쓰지 않습니다.** 모델이 기억하는 본문은 개역개정과 섞이거나 한두 글자가 틀립니다.
  반드시 아래 스크립트로 원문 페이지를 받아서 넣습니다.
- 받아온 글자를 고치지 않습니다. 맞춤법, 띄어쓰기, 옛 표현("가라사대", "하였느니라")을 그대로 둡니다.
  앞뒤 공백과 절 번호, HTML 태그만 걷어냅니다.

### 스크립트 `scripts/fill-verses.mjs`

새 파일로 만듭니다. 할 일:

1. `verses/daily-verses.refs.json`을 읽습니다.
2. 필요한 장을 `(book, chapter)`로 중복 없이 모읍니다. 모두 129장입니다.
3. 각 장을 이 주소에서 받습니다.
   ```
   http://www.holybible.or.kr/B_GAE/cgi/bibleftxt.php?VR=GAE&VL={book}&CN={chapter}&CV=99
   ```
   - `VR=GAE`가 개역한글입니다. 다른 값으로 바꾸지 않습니다.
   - 인코딩은 **EUC-KR**일 가능성이 높습니다. 응답 헤더나 `<meta charset>`을 보고
     `new TextDecoder('euc-kr')`로 풉니다. 한글이 깨지면 멈추고 보고합니다.
   - 요청 사이에 300ms 쉽니다. 받은 HTML은 `verses/.cache/{book}-{chapter}.html`에 저장해
     다시 실행할 때 재사용합니다. (`.cache/`는 `.gitignore`에 추가)
4. **파싱 방법은 먼저 한 장(요한복음 14장, `VL=43&CN=14`)을 받아 HTML 구조를 직접 보고 정합니다.**
   절 번호와 본문이 어떤 태그로 나뉘는지 확인한 뒤 파서를 씁니다. 구조를 추측해서 짜지 않습니다.
5. 각 구절의 `text`를 채워 `verses/daily-verses.json`으로 씁니다.
   `.refs.json`은 그대로 둡니다.

사이트가 막혀 있거나 구조가 달라 파싱이 안 되면, 다른 사이트로 바꾸지 말고 **멈추고 보고합니다.**

### 검사 — 전부 통과해야 다음 단계로

스크립트 끝에서 확인하고, 하나라도 실패하면 0이 아닌 코드로 끝냅니다.

| 검사 | 기준 |
| --- | --- |
| 개수 | 183 |
| 빈 본문 | 0개 |
| 개역한글인지 | 요한복음 14:6 본문에 `가라사대`가 들어 있음 (개역개정은 `이르시되`) |
| 1일차 | 시편 2:8, 본문에 `열방` 포함 |
| 길이 | 본문이 10자 미만이거나 300자 넘는 구절은 목록으로 출력 (파싱 실수 의심) |
| 깨진 글자 | `�` 포함 구절 0개 |

통과하면 아래 10개를 **본문 그대로** 출력합니다. 사용자가 눈으로 확인합니다.
1, 2, 3, 20, 50, 80, 100, 130, 160, 183번째.

커밋: `git commit -m "매일 말씀 183절 개역한글 본문 채움"`

## 2. 앱 데이터 파일

`verses/daily-verses.json`에서 `constants/dailyVerses.ts`(또는 앱에서 상수를 두는 곳)를 생성합니다.

```ts
export const VERSE_ATTRIBUTION = '성경전서 개역한글판 © 대한성서공회';

export type DailyVerse = {
  day: number;      // 1부터
  ref: string;      // '시편 2:8'
  text: string;     // 개역한글 원문
  theme: string;
};

export const DAILY_VERSES: readonly DailyVerse[] = [ /* 183개 */ ];
```

- 생성 스크립트로 만듭니다. 손으로 옮겨 적지 않습니다.
- `book`, `chapter`, `verse` 숫자는 빼도 됩니다. 나중에 성경 링크가 필요하면 다시 넣습니다.

## 3. 오늘의 말씀 고르기

`getTodayVerse(date = new Date())` 함수를 만듭니다.

- 날짜는 **한국 시간(Asia/Seoul)** 기준입니다. 서버·브라우저 시간대에 흔들리지 않게
  `Intl.DateTimeFormat('en-CA', { timeZone: 'Asia/Seoul' })`로 `YYYY-MM-DD`를 먼저 구합니다.
- 기준일 `2026-01-01`로부터 지난 날 수를 구하고, `DAILY_VERSES[일수 % 183]`을 돌려줍니다.
  음수가 나오면 `((n % 183) + 183) % 183`으로 바로잡습니다.
- 같은 날이면 모든 사용자가 같은 구절을 봅니다.

### 그룹 리더가 정한 말씀이 있으면 그게 먼저

오늘의 묵상 기능에서 그룹 리더가 오늘 말씀을 정해 두었다면 **그 말씀을 보여줍니다.**
정해 둔 게 없을 때만 `getTodayVerse()`를 씁니다.
그 기능이 아직 없으면 이 분기는 자리만 만들어 두고 보고합니다.

### 테스트

`getTodayVerse`에 jest 테스트를 추가합니다.
- 서울 기준 같은 날의 00:01과 23:59는 같은 구절
- UTC 15:00(서울 자정)을 기준으로 앞뒤가 다른 구절
- 183일 뒤는 같은 구절

커밋: `git commit -m "오늘의 말씀 선택 로직"`

## 4. 화면에 연결

지금 오늘의 묵상(또는 홈의 말씀 카드)에 고정 구절이 들어 있는 곳을 찾아 `getTodayVerse()`로 바꿉니다.

- 카드의 **위치, 구조, 버튼은 그대로** 둡니다. 들어가는 글자만 바뀝니다.
- 본문은 `fontFamily.serif`, 구절 표기(`시편 2:8`)는 지금 쓰는 스타일 그대로.
- 본문 아래에 출처를 **반드시** 표시합니다. 조건이기 때문에 빼면 안 됩니다.
  - 글자: `VERSE_ATTRIBUTION`
  - 스타일: 12, `colors.onSurfaceVariant`, 위쪽 간격 8
- 긴 구절(100자 넘는 것)이 카드에서 잘리지 않는지 봅니다. 잘리면 줄 수 제한을 풀고 보고합니다.

커밋: `git commit -m "오늘의 묵상에 매일 말씀 연결"`
